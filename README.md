# Айт: тренажёр трудных разговоров (ORTAQ 2026)

Веб-тренажёр: ИИ играет давящего собеседника (арендодатель, руководитель, продавец), студент учится отстаивать свои права. После диалога — разбор ошибок с цитатами, лучшие формулировки и шаблон письменного заявления. Языки: русский, казахский, английский.

**Это учебный тренажёр, а не юридическая консультация.**

## Запуск

```bash
npm install
cp .env.example .env.local   # отредактируйте
npm run dev                  # http://localhost:3000
```

Проверки: `npm run lint`, `npm test`, `npm run build`.

## Демо-режим (без интернета и без ключа)

`LLM_MOCK=true` — собеседник отвечает заготовленными репликами (`content/demo/<сценарий>.json`), разбор строится по ключевым словам в репликах студента, ИИ не вызывается. На страницах чата и разбора виден баннер «Демо-режим».

Скриншоты демо (ru, kk, мобильный вид): `docs/screenshots/`.

## Реальный режим

```
LLM_MOCK=false
LLM_API_KEY=...      # только на сервере, не коммитить
LLM_MODEL=claude-sonnet-5-5
```

Провайдер подключён в одном файле `lib/llm.ts`.

## Деплой на Render

1. На render.com: **New + → Blueprint**, подключите GitHub-репозиторий (Render попросит доступ к нему).
2. Render прочитает `render.yaml`. При создании спросит две переменные:
   - `LLM_MOCK` — `true` для демо без ИИ (безопасно для первого запуска) или `false` для реальной модели;
   - `LLM_API_KEY` — ключ Anthropic (нужен только при `LLM_MOCK=false`; хранится только в Render).
3. Автодеплой включён: каждый пуш в ветку из `render.yaml` пересобирает и перезапускает сайт. Ветку можно сменить там же (например, на `main`).
4. Проверка: открыть публичный адрес, пройти диалог → разбор → шаблон.

Бесплатный тариф усыпляет сервис после простоя (первый запрос ~1 минуту) и сбрасывает SQLite при перезапуске. Перед защитой откройте сайт заранее или возьмите платный тариф.

## Правовые справки

Модель не ссылается на законы из памяти. Правовые факты берутся только из `content/legal/<сценарий>.md`, которые заполняет человек по adilet.zan.kz. Строки с `TODO-VERIFY` игнорируются: пока справка не проверена, интерфейс и разбор не называют номера статей и сроки.

**Статус: черновики справок по трём сценариям составлены 19.11.2026 из текстов с adilet.zan.kz (Гражданский кодекс, Трудовой кодекс, Закон о защите прав потребителей). Они не проверены юристом: перед публикацией сверить с сайтом (дата редакции) и показать юристу.**

## Приватность

Не собираются имена и контакты, тексты диалогов не сохраняются (переписка живёт только в браузере). В SQLite (`data/app.db`) хранится анонимная статистика: сценарий, уровень, язык, число ходов, баллы и теги ошибок.

## Ограничения

- Казахский текст — черновик, ждёт проверки носителем (`content/i18n/KK-REVIEW.md`).
- Шаблоны заявлений есть на русском и казахском (казахские — черновик, нужна проверка носителем); для английского показывается русский шаблон с пометкой.
- Лимит запросов хранится в памяти процесса; SQLite на хостинге с эфемерной файловой системой сбрасывается при перезапуске.
- Историю диалога присылает браузер, поэтому реплики собеседника можно подменить; на защиту модели это влияет только в рамках одного собственного диалога, данные других пользователей недоступны.
- План работ: `PLAN.md`.
