# Тренажёр трудных разговоров (ORTAQ 2026)

Веб-тренажёр: ИИ играет давящего собеседника (арендодатель, руководитель, продавец), студент учится отстаивать свои права. После диалога — разбор ошибок с цитатами, лучшие формулировки и шаблон письменного заявления. Языки: русский, казахский, английский.

**Это учебный тренажёр, а не юридическая консультация.**

## Запуск

```bash
npm install
cp .env.example .env.local   # отредактируйте
npm run dev                  # http://localhost:3000
```

Проверки: `npm run lint`, `npm test`, `npm run build`.

## Демо-режим (без интернета и без ключа)

`LLM_MOCK=true` — собеседник отвечает заготовленными репликами (`content/demo/<сценарий>.json`), разбор строится по ключевым словам в репликах студента, ИИ не вызывается. На страницах чата и разбора виден баннер «Демо-режим».

Скриншоты демо: `docs/screenshots/`.

## Реальный режим

```
LLM_MOCK=false
LLM_API_KEY=...      # только на сервере, не коммитить
LLM_MODEL=claude-sonnet-5-5
```

Провайдер подключён в одном файле `lib/llm.ts`.

## Правовые справки

Модель не ссылается на законы из памяти. Правовые факты берутся только из `content/legal/<сценарий>.md`, которые заполняет человек по adilet.zan.kz. Строки с `TODO-VERIFY` игнорируются: пока справка не проверена, интерфейс и разбор не называют номера статей и сроки.

**Статус: справки по трём сценариям не заполнены.**

## Приватность

Не собираются имена и контакты, тексты диалогов не сохраняются (переписка живёт только в браузере). В SQLite (`data/app.db`) хранится анонимная статистика: сценарий, уровень, язык, число ходов, баллы и теги ошибок.

## Ограничения

- Казахский текст — черновик, ждёт проверки носителем (`content/i18n/KK-REVIEW.md`).
- Шаблоны заявлений только на русском.
- Лимит запросов хранится в памяти процесса; SQLite на хостинге с эфемерной файловой системой сбрасывается при перезапуске.
- План работ: `PLAN.md`.
