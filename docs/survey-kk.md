# Сынақ анкетасы: «Айт: күрделі әңгімелер тренажері»

> Ескерту: бұл аударма — жоба авторы тексеруге тиісті қазақ тіліндегі алғашқы нұсқа. Қолданар алдында қазақ тілін жетік білетін адамға көрсетіңіз.

Анкета анонимді: аты-жөніңізді, тобыңызды және байланыс деректеріңізді жазбаңыз. Толтыру 5–7 минут алады. Жауаптар тренажерді жақсарту үшін қажет, «жақсы/жаман» деген баға қойылмайды.

**Тренажер — оқу құралы, заңгерлік кеңестің орнын баспайды.** Ондағы әңгімелесуші — жасанды интеллект.

Барлық жерде 1–5 шкаласы: 1 = мүлде жоқ, 5 = толық иә.

# Жүргізушінің парағы (тестті өткізетін адам толтырады)

Қажет болмаса араласпаңыз: адамның қай жерде тоқтайтынын бақылаңыз. Аты-жөнін жазбаңыз, тек қатысушы коды (Қ1, Қ2, …).

| Код | Құрылғы | Алғашқы сөзге дейінгі уақыт | Қай жерде тоқтады / не сұрады | Интерфейс қатесі немесе ақау | ЖИ-дің немесе талдаудың біртүрлі сөзі (сөзбе-сөз) |
|---|---|---|---|---|---|
| Қ1 | | | | | |
| Қ2 | | | | | |
| Қ3 | | | | | |

**Міндетті түрде тексеріңіз**
1. Қатысушы «заңгерлік кеңес емес» деген ескертуді көмексіз байқады ма.
2. Қатысушы әңгімелесушінің жасанды интеллект екенін түсінді ме.
3. «Аяқтау» батырмасына және талдауға көмексіз жетті ме.
4. «Сіздің құқықтарыңыз» блогында заңгерлік кеңеске ұқсайтын бірдеңе болды ма.

**Нәтижелерді қалай пайдалану керек**

| Нені қараймыз | Жақсы | Алаңдатарлық (тапсырғанға дейін түзетеміз) |
|---|---|---|
| «Талдау түсінікті», «қателер дұрыс көрсетілген» орташа бағасы | ≥ 4 | < 3,5 |
| Сенімділіктің өсуі (Б1 − А3) | орташа ≥ +1 | ≤ 0 |
| Тренажерді заңгерлік кеңес деп қабылдағандар (Ә3.3) | 0 адам | кем дегенде бір адам |
| Ақаулар (Б3) | 10-ның ішінде ≤ 1 | 10-ның ішінде ≥ 3 |
| Ә2.1 және Ә3.2 тармақтары («қате/қауіпті») | жекелеген | әртүрлі адамдарда қайталанады |

Ә1.2, Ә2.1, Ә3.2 тармақтарында және жүргізуші парағында «біртүрлі» деп аталған нәрсенің бәрін кестеге түсіріңіз: сценарий, деңгей, тіл, сөзбе-сөз сөйлем. Осы кесте бойынша промпттар мен анықтамалар түзетіледі.
