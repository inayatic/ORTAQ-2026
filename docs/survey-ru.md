# Анкета тестирования: «Тренажёр трудных разговоров»

Анкета анонимная: имя, группу и контакты не указывайте. Заполнение занимает 5–7 минут. Ответы нужны, чтобы улучшить тренажёр, оценок «хорошо/плохо» мы не ставим.

**Тренажёр — учебный и не заменяет юридическую консультацию.** Собеседник в нём — ИИ.

Шкала 1–5 везде: 1 = совсем нет, 5 = полностью да.

# Лист ведущего (заполняет тот, кто проводит тест)

Не вмешивайтесь без необходимости: смотрите, где человек останавливается. Имена не записывайте, только код участника (У1, У2, …).

| Код | Устройство | Время до первой реплики | Где замешкался / что спросил | Ошибка интерфейса или сбой | Странная реплика ИИ или разбор (дословно) |
|---|---|---|---|---|---|
| У1 | | | | | |
| У2 | | | | | |
| У3 | | | | | |

**Проверить обязательно**
1. Увидел(а) ли участник предупреждение о том, что это не юридическая консультация, без подсказки.
2. Понял(а) ли участник, что собеседник — ИИ.
3. Дошёл(ла) ли до кнопки «Завершить» и до разбора без помощи.
4. Заметил(а) ли участник что-то в блоке «Ваши права», что звучало как юридический совет.

**Как использовать результаты**

| Что смотрим | Хорошо | Тревожно (чиним до подачи) |
|---|---|---|
| Средняя оценка «разбор понятен», «ошибки показаны верно» | ≥ 4 | < 3,5 |
| Рост уверенности (В1 − А3) | ≥ +1 в среднем | ≤ 0 |
| Те, кто принял тренажёр за юридическую консультацию (Б3.3) | 0 человек | хоть один |
| Сбои (В3) | ≤ 1 из 10 | ≥ 3 из 10 |
| Пункты из Б2.1 и Б3.2 («неверно/опасно») | единичные | повторяются у разных людей |

Всё, что названо в Б1.2, Б2.1, Б3.2 и в листе ведущего как «странное», перенесите в таблицу: сценарий, уровень, язык, дословная фраза. По этой таблице правятся промпты и справки.
